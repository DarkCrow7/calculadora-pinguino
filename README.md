# Calculadora Pingüino

Calculadora de escritorio hecha con Electron, JavaScript, HTML y CSS.

## Ejecutar en local

```bash
npm install
npm start
```

## Atajos de teclado

- `0-9`: números
- `+ - * /`: operadores
- `.`: decimal
- `Enter` o `=`: calcular
- `Backspace`: borrar último dígito
- `Escape`: limpiar todo

## Empaquetar app

```bash
npm run dist
```
